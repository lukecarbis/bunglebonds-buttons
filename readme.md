# Bunglebond's Buttons

Bunglebond's Buttons is an Owlbear Rodeo add-on that gives players quick, tactile control over their tokens using a keypad. It is built as a small Vite + TypeScript app that runs inside Owlbear Rodeo and bridges keyboard input to token actions.

Keyboard tool available here: https://drive.google.com/file/d/1OIcrcSHlXu9-JA7n-OVyzzy57Fsn0MaF/view

**Features**
1. Keypad-driven token controls for fast, repeatable actions.
2. Lightweight frontend built with Vite and TypeScript.
3. Owlbear Rodeo SDK integration for in-game token control.

**Requirements**
1. Node.js (LTS recommended).
2. npm (ships with Node.js).

**Install**
1. `npm install`

**Development**
1. `npm run dev`
2. Open the local dev server URL shown in the terminal.

**Build**
1. `npm run build`
2. Production files are emitted to `dist/`.

**Preview (Production Build)**
1. `npm run preview`
2. Open the local preview URL shown in the terminal.
